04 · Guía de Configuración

Optimización para Claude Code & Agentes

Cómo configurar tu servidor local (`llama.cpp` o `vLLM`) para maximizar la velocidad en bucles de agentes y evitar esperas de 30 segundos por turno.

1. Activa Prompt Caching (Esencial)

En agentes de código, el 81% de los tokens procesados son historial repetido. Con prompt caching, el prefill toma 0.8s en vez de 33s en documentos de 32k.

--prompt-cache /path/cache.bin --cache-type-k q8_0

2. Usa Multi-Token Prediction (MTP)

Modelos como Ornith 1.5 y Qwen 3.8 traen cabezales MTP embebidos. En código estructurado y tool calls logran +40% a +90% de velocidad gratis sin perder precisión.

--spec-type draft-mtp --spec-draft-n-max 3

3. Comando Completo para llama-server

Lanza tu modelo con soporte para Flash Attention, context window largo de 131k y cuantización inteligente de KV Cache:

llama-server -m ornith-35b-q4_k_m.gguf -c 131072 -fa -ngl 999 --cache-type-k q8_0 --cache-type-v q8_0 --spec-type draft-mtp --port 8080
